How this works

  • The real btop. One copy runs on the homelab in a pseudo-terminal. Its output goes to every viewer over Server-Sent Events and is drawn by xterm.js, so a hundred visitors cost the same as one.
  • View only. Nothing you type or click reaches it, and the process list is switched off so no program names leak.
  • Locked down. Every container is read-only with no Linux capabilities, and Docker is only visible through a proxy that allows two read-only calls.
  • No open ports. Traffic reaches the box through an outbound Cloudflare tunnel. No cookies, no analytics, nothing stored about you.
